Используй скиллы frontend-design, animate, emil-design-eng, apple-design. Нужен ВАУ-эффект с первых секунд при сохранении деловитости B2B.

ЗАДАЧА
Новый дизайн сайта zao.sncard.ru — АО «НПФ «Сибнефтекарт» (Томск, бренд «СНК»). Одностраничная главная из четырёх блоков: карта АЗС → о компании → новости → контакты. Адаптив: desktop 1440, tablet 768, mobile 390.
Файлы: zao-sncard/index.html, zao-sncard/styles.css, zao-sncard/main.js.

ДИЗАЙН-СИСТЕМА: НАСЛЕДОВАНИЕ ОТ designs/
Сайт в папке designs/ (index.html, styles.css, main.js, ui-kit.html, BRIEF.md) — эталонный код-дизайн для всех сайтов группы. Его НЕ изменять.
- Сначала прочитай designs/BRIEF.md, designs/styles.css, designs/ui-kit.html и designs/main.js — пойми токены, компоненты и приёмы анимации.
- Стили наследуются, а не копируются: в index.html подключи сначала ../designs/styles.css, затем свой zao-sncard/styles.css. В своём файле — только новые компоненты (карта, фильтры, список АЗС, блоки компании/новостей/контактов) и точечные переопределения.
- Используй существующие токены (--bg, --surface, --text, --accent, --line, --blueprint, --blueprint-soft, --watermark, --ease, --t-ui, --r-sm/md/lg, --shadow-sm/md, --gutter, --gap) и классы (.container, .btn и модификаторы, .h2, .section-head, .mono, .dotgrid, шапка, выпадающие меню, футер, форма рассылки). Новых цветов не вводить; если без токена не обойтись — объяви его в :root своего styles.css с комментарием.
- Поведение (курсор, магнитные кнопки, шапка со сжатием и прогрессом, FLIP-индикатор меню, dropdown с клавиатурой, Lenis, reveal-анимации, count-up, чекбокс/кнопка «Подписаться» в футере): если designs/main.js можно подключить без ошибок на странице без hero/pinned-сцены — подключи его; иначе перенеси нужные функции в свой main.js в том же стиле (единый rAF-тикер, IntersectionObserver), не трогая оригинал.
- Шапка, футер, кнопки, карточки, фокус-состояния и типографика визуально должны быть узнаваемо «из той же семьи», что и designs/.

КОНЦЕПЦИЯ
Та же «Живая схема», что в designs/: светлый инженерный чертёж, точечная сетка, тонкие линии, моно-подписи и координатные засечки, красный — единственный дозированный акцент. Строго светлая тема, никаких тёмных залитых блоков (включая меню, попапы карты и футер).

СТРУКТУРА

0. Intro (как в designs/: монограмма «СНК» прорисовывается линией, сетка раскрывается; ~1.5 с, пропуск кликом, один раз за сессию). Переходом из intro должна «проявляться» карта.

1. Header — из designs/, пункты меню-якоря: Карта АЗС · О компании · Новости · Контакты; справа «Личный кабинет» с замком. Активный пункт переключается по скроллу (scroll-spy) с FLIP-индикатором.

2. Блок 1 — «Карта АЗС» (первый экран, главный вау-момент)
- Полноширинная карта почти на весь вьюпорт (100svh минус шапка), поверх — светлая панель слева (desktop) / нижний sheet (mobile): заголовок, счётчик АЗС (count-up), поиск по адресу, фильтры по топливу и услугам (чипы), список АЗС.
- Карта: Leaflet с cdnjs (закреплённая версия) + светлая подложка без лишнего шума (например CARTO Positron / light_nolabels), приглушённая CSS-фильтром под палитру --blueprint. Если выберешь другой движок — обоснуй. Карта должна выглядеть как лист чертежа: точечная сетка/засечки по краям, моно-координаты курсора в углу, масштабная линейка в стиле размерных меток.
- Маркеры — собственные inline-SVG «узлы схемы» с условными обозначениями из karta-azs (разные иконки/формы для типов объектов и услуг), кластеризация (Leaflet.markercluster с cdnjs) с числом в моно-шрифте.
- Легенда условных обозначений — отдельная сворачиваемая карточка.
- Анимации: при появлении маркеры «зажигаются» каскадом от Томска наружу (stagger по расстоянию), между соседними АЗС на мгновение пробегают тонкие линии-«данные»; hover по маркеру — красный контур и чип со спецификацией (адрес, топливо, услуги); клик по маркеру или строке списка — плавный flyTo, раскрытие карточки АЗС (кнопка «Построить маршрут» — ссылка на Яндекс.Карты с координатами), синхронная подсветка строки в списке. Фильтры — маркеры не исчезают резко, а гаснут/сжимаются (opacity + scale), список перестраивается с FLIP.
- Скролл колесом над картой не должен «захватывать» страницу: зум карты — по Ctrl/⌘+колесо или кнопкам, подсказка об этом появляется ненавязчиво.
- Без JS и при ошибке загрузки карты — читаемый список АЗС с адресами.

3. Блок 2 — «О компании»
Текст и факты со страницы /company, подача в стиле designs/: моно-метка, крупный H2 с построчным появлением, 3–4 метрики с одометром (только реальные цифры со страницы, иначе TODO), таймлайн истории/направления в виде линии чертежа, которая дорисовывается по скроллу, мини-схема (узлы АЗС ↔ сервер ↔ нефтебаза) в духе hero из designs/. Ссылки на «История компании» и «Акционерам», если такие разделы есть на сайте.

4. Блок 3 — «Новости»
Реальные новости с /news: горизонтальный ряд карточек (дата моно-шрифтом, тег, заголовок, «Читать») с drag-scroll и инерцией, кастомный курсор «Тяни» на desktop, свайп на mobile — как в designs/. Ссылка «Все новости».

5. Блок 4 — «Контакты»
Данные с /contacts: адрес, телефоны, e-mail, отделы (карточки с копированием телефона/почты в буфер и микро-подтверждением), режим работы. Небольшая карта-схема офиса в Томске в том же чертёжном стиле (не дублировать тяжёлую карту из блока 1 — можно статичный SVG или облегчённый вид). Финальный CTA «Обсудим вашу задачу?» с магнитной красной кнопкой.

6. Footer — из designs/ (контакты, правовая информация, рассылка, водяной знак «СНК» с прорисовкой обводки), © АО «НПФ «Сибнефтекарт», 2026.

ИЗ BRIEF.md (сохранить)
- Шрифты Manrope 700–800 (плотный трекинг) + JetBrains Mono, кириллица.
- Единая кривая cubic-bezier(0.22, 1, 0.36, 1), появления 400–900 мс, UI-реакции ≤ 200 мс.
- Курсор (точка + кольцо) и магнитные кнопки только при (pointer: fine), системный курсор не скрывать.
- Lenis для плавного скролла (кроме области карты), отключается при prefers-reduced-motion.
- Анимировать transform и opacity, will-change точечно, IntersectionObserver, единый rAF-тикер, цель 60 fps; на мобильных упростить (меньше линий-данных, без курсора и tilt). Первый экран интерактивен быстрее 2 с, тайлы и кластеры не блокируют клики.
- Стек: чистые HTML/CSS/JS без сборки; GSAP 3 (+ScrollTrigger), Lenis, Leaflet (+markercluster) — только с cdnjs с закреплёнными версиями. Иконки — inline SVG, фото не использовать.
- Доступность: без JS страница читаема (начальные состояния анимаций — через класс .js на <html>); reduced-motion — всё сразу в финальном состоянии; видимый фокус (красное кольцо 2px с отступом); список АЗС и фильтры полностью доступны с клавиатуры, маркеры имеют aria-label; контраст AA; язык — русский.
