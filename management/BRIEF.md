ЗАДАЧА
Новый дизайн веб-приложения management.sncard.ru — «Управление продуктами СНК» (ООО «Сибнефтекарт», Томск, бренд «СНК»). Это не лендинг, а рабочий кабинет: партнёры и сотрудники мониторят точки обслуживания (ТО), контролируют заявки, управляют Hasp-ключами, лицензиями, спецификациями, справочниками, складом и обновлениями. Нужен интерактивный прототип в новом дизайне, по которому потом перевёрстывается боевое приложение. Адаптив: desktop 1440 (основной), laptop 1280, tablet 768, mobile 390 (упрощённо: просмотр и ключевые действия).
Папка: management/.

ЧТО СЕЙЧАС НА САЙТЕ (итог разбора)
- SPA на Vue 3 + Pinia + vue-i18n + PrimeVue (DataTable, TreeTable, Dialog, ConfirmDialog, Toast, Paginator, Panel, Tag, FloatLabel, Textarea) + Tailwind; есть тёмная тема; вход через OAuth2 (Authentik); живые данные по WebSocket (NATS). Без авторизации виден только экран входа.
- Три продукта в одном приложении: «СНК-АЗС», «СНК-Офис», «Администрирование».
  · СНК-АЗС: Мониторинг ТО, Информация по ТО (вкладки: информация, события, версии файлов, команды, операции, мобильные сервисы, заявки, статистика), мобильные сервисы — Активность, Контроль заявок, Статистика.
  · СНК-Офис: Информация по смене (остатки в резервуарах, ресурсов и товаров, реализация топлива, расход по ТРК), Справочники (точки обслуживания, товары, юрлица, ведомости, инкассаторы и направления инкассации, операторы, поставщики/перевозчики/грузоотправители), Управление складом (поставки, перемещение, списание, оприходование ТМЦ, прайс-листы; карточка документа), Аналитика (динамика реализации), Отчёты.
  · Администрирование: Организации → карточка организации (информация, обновления, сервисы партнёра, договоры → спецификации, лицензии, квоты по клиентам, пользователи → ТО пользователя и привилегии, перекодировка топлива, АЗС, офисное ПО, Hasp-ключи), Пользователи, Эмитенты, Внешние ТО, Лицензии, Справочники, Выпуск и загрузка обновлений, Обновление приложения, Журнал изменений, Создание новостей.
  · Также: дашборд (/dashboard), профиль.
  · Общее: профиль, уведомления, инструкция пользователя, cookie-баннер, правовые документы, баннеры «Вышла новая версия», «WebSocket недоступен», «Временно недоступно».
- Полный список разделов, названия полей, статусов и сообщений — в словаре i18n боевого бандла (https://management.sncard.ru/ → /assets/i18n-*.js, объект ru). Разбери его сам на этапе 1; в бриф и в код его целиком не переносить — брать только то, что нужно для прототипируемых экранов.

НОВЫЕ КОМПОНЕНТЫ (в ui-kit их нет — спроектировать через design:design-system и собрать на странице management/ui-kit.html)
- Каркас: сайдбар с тремя продуктами и группами разделов (сворачиваемый до иконок, на mobile — выезжающий), верхняя панель (переключатель продукта, хлебные крошки моно-шрифтом, глобальный поиск по разделам, уведомления, профиль), шапка страницы (H1, действия, счётчики).
- Таблица данных: сортировка, фильтры в заголовках, поиск, выбор строк, массовые действия, липкий заголовок и первая колонка, выбор видимых колонок, плотность (компактная/обычная), пагинация, раскрытие строки. Дерево-таблица для привилегий и иерархий.
- Формы: текст, textarea, select, multiselect с поиском, выбор даты и периода, переключатель, радио, числовое поле, загрузка файла (drag-and-drop, прогресс), валидация inline.
- Статусы: теги статусов ТО и заявок, индикатор «живых» данных (пульс), отметка «данные могут быть не актуальны».
- Оверлеи: модалка, подтверждение действия («Что произойдёт» + комментарий), боковая панель деталей (drawer), тост, тултип, выпадающее меню действий, панель уведомлений.
- Данные: KPI-плитки, графики (столбцы, кольцо, линия) — по dataviz, в палитре группы; вкладки; аккордеон/панель; степпер для многошаговых форм.
- Состояния: скелетоны загрузки, пустое состояние («Нет данных» с чертёжной иллюстрацией), ошибка сервера, баннеры новой версии и потери WebSocket.
Для каждого компонента в ui-kit: все состояния (default, hover, focus, active, disabled, loading, error) и пометка, какому компоненту PrimeVue он соответствует.

КОНЦЕПЦИЯ
«Живая схема», но в рабочем режиме: чертёж остаётся фоном и характером, а не шоу. Точечная сетка и засечки — на экране входа, в шапке страницы и в пустых состояниях; моно-шрифт — для кодов, номеров, дат, версий и цифр (табличные цифры); красный — только главное действие, выделение и ошибки. Плотность выше, чем на сайтах: это инструмент, в котором работают часами. Анимации — короткие и функциональные (появление данных, смена статусов, открытие панелей); никаких intro, pin-сцен и параллакса внутри кабинета.

ЭКРАНЫ ПРОТОТИПА
Все 57 разделов не рисуем — делаем опорные экраны, остальные собираются из тех же шаблонов (список этих соответствий дай в итоге).
1. Вход (единственный «вау»): слева форма входа через учётную запись СНК (кнопка OAuth, TODO), справа чертёжная схема «ТО → сервер → офис» с бегущими по линиям пакетами (приём из designs/); cookie-баннер, правовые ссылки, адрес и © внизу.
2. Мониторинг ТО: KPI-плитки (всего, онлайн, с ошибками, без связи), таблица ТО со статусами и «живым» обновлением, фильтры; переключатель «таблица / карта» (карта-схема точек, как облегчённая карта в sncard/ — без тяжёлых зависимостей).
3. Информация по ТО: шапка точки, вкладки — колонки и пистолеты (визуальная схема ТРК с состояниями), транзакции (таблица), версии файлов, активность.
4. Контроль заявок + Статистика: таблица заявок со статусами, drawer с деталями и действиями; графики по часам и по статусам.
5. Карточка организации (Администрирование) с вкладками; внутри — Hasp-ключи и активация ключа: список ключей; активация — пошаговая форма со степпером и итоговым подтверждением.
6. Спецификация (добавить/редактировать): длинная форма с секциями, липкая панель «Сохранить / Отмена», предупреждение о несохранённых изменениях.
7. Справочник СНК-Офиса (например «Товары»): типовой CRUD — таблица, создание/редактирование в модалке, удаление с подтверждением, импорт/экспорт.
8. Склад: список документов ТМЦ и карточка документа с табличной частью (строки товаров, итоги моно-шрифтом).
9. Администрирование: пользователи и привилегии (дерево прав с чекбоксами и поиском), выпуск обновления (загрузка файла, версия, журнал изменений).
10. Профиль и панель уведомлений; экраны ошибок и пустых состояний.
11. Дашборд (стартовый экран после входа, /dashboard): обзор по трём продуктам — ключевые цифры, проблемные ТО, свежие заявки и события, быстрые переходы.
12. Информация по смене (СНК-Офис): выбор ТО и смены, вкладки — остатки в резервуарах (резервуары в разрезе чертёжным SVG с уровнем, как в hero designs/), остатки ресурсов и товаров, реализация топлива, расход по ТРК.

Боевого API у прототипа нет. Демо-данные — в management/data/demo.js: немного правдоподобных записей на каждый экран (5–30 строк, для пагинации — генерация), явно помеченных как демо. Реальные названия разделов, полей и статусов — из словаря i18n; реальные адреса, реквизиты и контакты клиентов не использовать. Живые обновления имитировать таймером (TODO: заменить на NATS).

СТЕК
Чистые HTML/CSS/JS без сборки, как в группе. Страницы — статический HTML, общий каркас (сайдбар, топбар) вставляет dev-скрипт management/tools/generate.mjs между маркерами (по образцу sncard/tools/generate.mjs). Скрипты: общий слой management/js/app.js (каркас, таблица, формы, оверлеи, тосты) + скрипты экранов отдельно. GSAP — только для экрана входа, локальная копия из sncard/js/vendor/; внутри кабинета — CSS-переходы и Web Animations API. Без Lenis и кастомного курсора внутри кабинета (системный скролл и курсор — норма для рабочего инструмента). Иконки — inline SVG в стиле designs/.

ИЗ designs/BRIEF.md (сохранить)
- Шрифты Manrope + JetBrains Mono, кириллица.
- Кривая cubic-bezier(0.22, 1, 0.36, 1); UI-реакции ≤ 200 мс, появления панелей и модалок 200–300 мс; ничего не мешает кликам.
- Анимировать transform и opacity; таблицы на 500+ строк не тормозят (виртуализация или пагинация).
- Доступность: полная работа с клавиатуры (таблицы, меню, модалки с ловушкой фокуса и Esc, drawer, выбор дат), видимый фокус (красное кольцо 2px с отступом), aria для сортировки, статусов и живых регионов (тосты, обновления), контраст AA, reduced-motion — без движения; язык — русский.
