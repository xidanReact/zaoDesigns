ЗАДАЧА
Главная страница корпоративного сайта АО «НПФ «Сибнефтекарт» (Томск, бренд «СНК») — разработчика оборудования и ПО для автоматизации АЗС и нефтебаз. Нужен вау-эффект с первых секунд при сохранении деловитости B2B. Только главная страница, адаптивная (desktop 1440, tablet 768, mobile 390).
Файлы: designs/index.html; допускается вынести стили и скрипты в designs/styles.css и designs/main.js.

КОНЦЕПЦИЯ: «ЖИВАЯ СХЕМА»
Страница — инженерный чертёж, который оживает: точечная сетка, тонкие линии, размерные метки, координатные засечки, моно-подписи (ТРК-01, РП-02), по линиям бегут данные. Красный — единственный акцент, использовать дозированно. Строго светлая тема: никаких тёмных и чёрных залитых блоков, включая прелоадер, футер и выпадающие меню.

СТРУКТУРА И АНИМАЦИИ

0. Intro (~2 с, пропускается кликом, один раз за сессию через sessionStorage)
   Белый экран, монограмма «СНК» (SVG-заглушка с золотисто-серебристым градиентом) прорисовывается линией (stroke-dashoffset), затем чертёжная сетка «раскрывается» и открывает страницу.

1. Header + главное меню
- Слева логотип «СНК», «Сибнефтекарт», подпись «акционерное общество «Научно-производственная фирма»». Справа контурная кнопка «Личный кабинет» с иконкой замка (при hover дужка замка «защёлкивается»).
- Меню: Новости; О компании ▾ («История компании», «Акционерам»); Контакты ▾ («Отдел по работе с клиентами», «Администрация», «Местоположение на карте»); Сеть АЗС.
- Шапка белая. При скролле сжимается (88→64px), сверху появляется тонкая красная полоса прогресса чтения.
- Индикатор активного пункта плавно перетекает между пунктами (FLIP).
- Выпадающие меню: белые карточки, радиус 12, мягкая тень, пункты появляются каскадом (stagger 40 мс). Открытие по hover, клику и клавиатуре (Esc, стрелки), aria-expanded.
- На мобильных бургер с полноэкранным светлым меню.

2. Hero (12 колонок: текст 5, сцена 7)
- Моно-метка «АВТОМАТИЗАЦИЯ АЗС И НЕФТЕБАЗ · ТОМСК».
- H1: «Оборудование и программное обеспечение для автоматизации АЗС и нефтебаз». Появление построчно (маска + translateY, stagger). Под словами «автоматизации АЗС» рисуется красная линия.
- Подзаголовок в 1–2 строки; кнопка «Связаться с нами» (красная, магнитная) и контурная «Направления деятельности» (якорь).
- Интерактивная сцена справа (inline SVG, линии 1.5px цветом --blueprint, заливки белые или --surface): резервуары в разрезе, трубопровод, ТРК, навес АЗС, кассовый терминал, сервер/облако, нефтебаза.
  · Линии дорисовываются в порядке потока: резервуары → трубопровод → ТРК → касса → сервер → нефтебаза.
  · По трубопроводам и линиям данных бегут красные «пакеты» (точки 4–6px), движение через getPointAtLength и requestAnimationFrame, разные скорости, бесконечный цикл. Поверх схемы лёгкие частицы данных на canvas, если это не роняет fps.
  · Уровень в резервуарах мягко «дышит»; на дисплее ТРК крутятся цифры-заглушки; на терминале мигает индикатор.
  · Параллакс за курсором в 3 слоя (lerp).
  · Hover по узлу (ТРК, резервуар, касса, нефтебаза): красный контур, подсветка связанных линий, рядом выезжает чип со спецификацией (моно-шрифт, текст-заглушка).

3. Бегущая строка под hero
   «Автоматизация АЗС · Нефтебазы · Программное обеспечение · Оборудование · Томск». Бесшовная, скорость зависит от скорости скролла, при hover замедляется.

4. Закреплённая сцена «Как работает система» (главный вау-момент, scroll-scrubbed)
   Секция закрепляется (pin) на ~4 экрана скролла. Слева 4 шага-заглушки (01–04, названия придумай нейтральные, без выдуманных технических подробностей), активный шаг подсвечен, остальные приглушены, рядом вертикальная красная шкала прогресса. Справа большая схема: «камера» плавно панорамирует и масштабирует (transform) между зонами: резервуарный парк → колонка → касса → офис/сервер → сеть АЗС; линии дорисовываются по прогрессу скролла. На мобильных без pin: шаги идут вертикально, схема появляется по частям.

5. Метрики
   3–4 ячейки, числа-заглушки (значения в data-target с комментарием TODO, реальных цифр не выдумывать). Count-up с эффектом одометра при появлении.

6. «Направления деятельности» (bento, 12 колонок)
   Карточки разного размера: «Оборудование для АЗС» (крупная, 6, с мини-схемой), «Программное обеспечение» (3), «Автоматизация нефтебаз» (3), «Сеть АЗС» (широкая, со ссылкой). Нумерация 01–04 моно-шрифтом, иконка-контур, текст-заглушка, стрелка.
- Spotlight: мягкий светлый радиальный градиент следует за курсором внутри карточки, рамка подсвечивается.
- Tilt не более 4°, только для pointer: fine.
- Мини-схема оживает при hover; стрелка «уезжает» и возвращается; рамка и стрелка краснеют.
- Появление со stagger и scale 0.96→1.

7. «Новости»
   Горизонтальный ряд карточек-заглушек (дата моно-шрифтом, чип-тег, заголовок-заглушка, «Читать») с drag-scroll и инерцией на desktop, свайп на mobile; над рядом кастомный курсор с подписью «Тяни». Ссылка «Все новости».

8. Финальный CTA-блок перед футером
   Крупный заголовок-заглушка «Обсудим вашу задачу?» и красная магнитная кнопка.

ГЛОБАЛЬНЫЕ ЭФФЕКТЫ
- Курсор: красная точка + кольцо с lerp, растёт над интерактивными элементами. Только при (pointer: fine), системный курсор не скрывать.
- Магнитные кнопки: притяжение в радиусе ~80px, смещение до 8px.
- Плавный скролл (Lenis), отключается при prefers-reduced-motion.
- Единая кривая cubic-bezier(0.22, 1, 0.36, 1) для появлений, 400–900 мс; UI-реакции (hover, нажатия) не дольше 200 мс.
- Разрешены mix-blend-mode: multiply для мягких светлых бликов, SVG-фильтры для «чертёжной» текстуры линий, clip-path reveal-переходы между секциями, backdrop-filter там, где он реально уместен (тема остаётся светлой).
- Производительность: анимировать преимущественно transform и opacity, will-change точечно, IntersectionObserver, единый rAF-тикер, без layout thrashing. Цель 60 fps. Первый экран интерактивен быстрее чем за 2 секунды, анимации не блокируют клики. На мобильных упростить: меньше пакетов, без tilt, без курсора, без canvas-частиц.

СТЕК
Чистые HTML/CSS/JS, без React/Vue и сборки. Разрешены GSAP 3 (core + ScrollTrigger) и Lenis с cdnjs с закреплённой версией. Иллюстрации и иконки — inline SVG, фото не использовать.

ДОСТУПНОСТЬ И ОТКАЗОУСТОЙЧИВОСТЬ
- Без JS страница читаема и выглядит финально: начальные состояния анимаций выставляет JS (класс .js на <html>).
- При prefers-reduced-motion всё сразу в финальном состоянии: без параллакса, курсора, движения ленты и pin.
- Видимые focus-состояния (красное кольцо 2px с отступом), навигация меню с клавиатуры, контраст AA.
- Язык интерфейса — русский.
